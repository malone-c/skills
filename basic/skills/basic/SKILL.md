Make it look like an academic 90s programmer's homepage.

Times New Roman only, no monospace. Very simple, minimal styling. It is acceptable to have no styling at all except for layout and document structure. Any styling should be purely functional and optimise primarily for usability.

Avoid extra textual exposition. Minimise the number of elements that have text at all. Where there is text, it should be easy to understand at a quick glance by a tired person in a hurry.
