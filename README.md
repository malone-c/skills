# skills

A collection of Claude Code skills and templates, one folder per collection.

| Folder | What it is |
| --- | --- |
| [`human-friendly-prs/`](human-friendly-prs/) | Skills for PR descriptions, code reviews and review-comment replies: short bullets for humans, long context folded into a dropdown for the next agent. |
| [`design/`](design/) | House style for web pages and slide decks — plain Times New Roman on white, melange dark when the system asks for it, plus a script for dithering images. |

Nothing here is published yet. Each folder's README says what has to go back in before it
is.
